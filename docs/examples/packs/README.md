# Starter packs

Optional presets the wizard can load in the "What jobs" step. Every pack uses **fictional
sample data only** (persona "Alex Example", `example.com` addresses, `555-01xx` phone numbers).
Never copy anyone's real profile, answers, ban list, or notes into a pack.

Each pack is a JSON file with `preferences` and `answers` objects. These were written for the
archived Electron scaffold's schema (branch `archive/electron-scaffold`); M7 maps them onto the
LangHire-based profile, saved searches, and Q&A store.
